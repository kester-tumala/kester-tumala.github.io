# Kester Tumala — Portfolio Website

A responsive, multi-page portfolio built with HTML5, CSS3, and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About and education
- `skills.html` — Skills and tools
- `projects.html` — Selected projects
- `contact.html` — Contact form (opens the visitor's email application)

## Run locally
1. Extract the ZIP file.
2. Open the `kester-portfolio` folder.
3. Double-click `index.html` to open it in your browser.

Recommended: open the folder in Visual Studio Code and use the **Live Server** extension. Right-click `index.html` and choose **Open with Live Server**.

You can also place the folder inside `C:\xampp\htdocs\` and visit:
`http://localhost/kester-portfolio/`

No database or build tools are required.

## Personalize before publishing
1. Replace `assets/images/profile-placeholder.svg` in the HTML references with your own photo path, for example `assets/images/profile.jpg`. Put your image in that folder.
2. Replace `your-email@example.com` in `contact.html`, `index.html`, and `js/script.js` with your actual public contact email.
3. Update GitHub and LinkedIn links to your real profiles.
4. Replace the sample CV link `assets/Kester-Tumala-CV.pdf` with your actual PDF CV. Add the PDF to the `assets` folder, or remove the Download CV button until you have one.
5. Confirm your education details, skills, skill indicators, and project descriptions. Project statuses in this starter are examples; keep only statements that accurately reflect your work.
6. Add real project screenshots and repository/demo links when available.

## Contact form note
The contact form uses a `mailto:` link. It does not send email directly and requires the visitor to have an email application configured. For a server-backed form, connect a service such as EmailJS or build a backend endpoint.

## External assets
Google Fonts and Font Awesome are loaded from their CDNs, so an internet connection is needed for those fonts and icons. The rest of the website is local.
